# Native terminal wall iteration

This iteration adds a production GPUI/Ghostty observation window and authenticated native pane admission. It is a bounded N6.2 implementation checkpoint; it does not close the complete N6.2 accessibility or sustained-load gate. The adjacent JSON receipt identifies the tested source, binaries, commands and limits.

Each wall belongs to one visible run ID. Reopening the same run reuses its open window. Up to four current assignments have separate native surfaces; the operator can enlarge one agent. Narrow windows show a selected agent, and the read-only transcript wraps retained messages and events. The main workbench remains available for steering and evidence.

The server verifies the attempt belongs to the run, its checked host/OMP ownership, the private socket and the exact tmux pane, host PID, owner session and attempt window. Numeric PID equality alone cannot admit a terminal. The desktop repeats socket identity checks and invokes a fresh authenticated verification in its observer child. Connection metadata contains no host or provider credentials. Unknown ownership refuses attachment.

Observers use unique grouped sessions with independent selected windows, `read-only,ignore-size`, and `destroy-unattached`. Runner windows use manual sizing at native launch and verified recovery because `ignore-size` alone can resize an otherwise unattached window. Closing the wall or whole GUI removes observer clients while preserving the daemon and agents. The renderer separately blocks typing, paste and terminal-directed wheel input; drag selection and Cmd+C remain available. Saved history is read through the transcript, without making tmux writable for scrolling.

Native child views hide when displaying the transcript or another selected agent. Process state and observation state are displayed separately. A service outage retains text, marks it stale, hides terminal surfaces and disables reconnect. Recovery reads fresh run state before showing connected observations. Terminal silence cannot mark work complete.

The iteration also repairs retained-input focus loss. When a focused field disappears, focus returns to a surviving rendered ancestor. Global Quit always consults the main workbench's draft guard, including when an Agent wall is active.
