# Use OMP, tmux, and Rust Agent Mail for the local runtime

On 2026-09-27, after [14 bounded contract checks passed](../testing/rust-mail-results-2026-09-27.md), the operator approved OMP 18.3.1 processes controlled through per-agent RPC hosts, tmux 3.7c for hosting and observable terminal views, and standalone Rust Agent Mail v0.3.36 for external messaging. Rust Mail passed the restart-deduplication case that failed with Relaycast, while the combined stack demonstrated independent agents, different model assignments, passive monitoring, and explicit replacement using saved input; no fallback or custom mailbox was needed. Crewroom retains workflow authority, ownership, model policy, revision-bound evidence, and external-action reconciliation: finite mailbox retry retention and unproven child-tool/supervisor recovery require the remaining [architecture contracts](../architecture.md#validation-and-remaining-integration-contracts), and tmux keystrokes or OMP's internal team bus are not the message transport.
